Nav & Footer

This page exists as a single place to preview the two components that repeat across every other page — index.html, about.html, contact.html, login.html, and dashboard.html — so any change here can be copied into the rest of the site in one pass. Try resizing the window to see the nav collapse into the mobile menu at 760px.

Navigation

<header class="site-nav"> — sticky, active-link underline, "Log in" as a corner button, mobile toggle
  • Wordmark links home from every page.
  • Log in lives in .nav-right, styled as a .btn.btn-secondary, rather than inside .nav-links — it reads as an action, not a nav destination.
  • The active link gets a blue underline via .nav-links a.active, set automatically by js/main.js based on the current filename.
  • The status pill ( All systems normal) is the recurring signature element, echoed again on the Dashboard as real status data.
  • Below 760px width, the nav links collapse behind the hamburger button; the Log in button stays visible in the corner.
